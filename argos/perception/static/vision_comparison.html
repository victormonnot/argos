How to read this view

Both panels use the same JPEG. Boxes, confidence and temporary display IDs come from each model's independent replay. IDs are not matched between models and do not count people.

Count navigation finds unequal detection counts only. Equal counts can still have different boxes. These sampled images and offline timings do not establish accuracy, a model winner or live performance.

Native replay keeps its original overlays. This export shows the recomputed comparison; its cursor uses the image's archived availability time.
